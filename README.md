# TopoMap

A web map built on [MapLibre GL JS](https://maplibre.org/) and the open
[Mapterhorn](https://mapterhorn.com/) terrain tiles (3D terrain, hillshade, elevation tint).

## Run

```sh
npm install
npm run dev      # live-reloading dev server at http://localhost:5173
npm run build    # static production build in dist/
```

Terrain data: © Mapterhorn and its [data sources](https://mapterhorn.com/attribution).
